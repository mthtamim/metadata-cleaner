২ · কী মুছবেন বেছে নিন

প্রতিটি ফিল্ডের পাশে মোড বেছে নিন: “যেমন আছে” = হাত দেওয়া হবে না, “নতুন মান বসান” = লেখা মানটি সব ফাইলে বসবে, “মুছে ফেলুন” = ওই নির্দিষ্ট ফিল্ডটাই মুছবে (ক্যাটাগরি বাছা না থাকলেও)।

প্রিসেট জায়গা:

“বসান” মোডে GPS না থাকলেও নতুন করে যোগ হয়। সরানো/রাউন্ড শুধু যেসব ফাইলে GPS আছে সেগুলোতে কাজ করে।

সব ফাইলের টেক্সট মেটাডেটায় খুঁজে বদলে দেয় — বদলটা প্রতি-ফাইলের এডিট হিসেবে বসে (আসল Clean-এর সময় লেখা হয়)।

একটা ফাইলের মেটাডেটা বাকি সব ফাইলে কপি করুন — যেমন একটা ছবির GPS/তারিখ বাকিগুলোতে বসানো।

বর্তমান মুছা + বদলানোর সেটিং একটা নামে সেভ করে রাখুন, পরে এক ক্লিকে ফিরিয়ে আনুন।

৩ · স্ক্যান রেজাল্ট

ডুপ্লিকেট ফাইল অটো শনাক্ত হয় — প্রতিটি ফাইলের SHA-256 হ্যাশ মিলিয়ে হুবহু কপিগুলোতে “ডুপ্লিকেট” ব্যাজ লাগে।

এখনো কোনো ফাইল যোগ হয়নি। ফাইল যোগ করলেই এখানে প্রতিটি ফাইলের মেটাডেটা দেখা যাবে।

৪ · রিপোর্ট

    এই সেশনে যা যা হলো (স্ক্যান, ক্লিন, এডিট, এক্সপোর্ট) — সময়সহ তালিকা। পেজ বন্ধ করলে মুছে যায়।

      ভিডিওর মেটাডেটা মোছা, ফোল্ডার-ওয়াচ (নতুন ফাইল এলে অটো-ক্লিন), শিডিউল আর Windows .exe — এগুলোর জন্য একই টুলের Python ডেস্কটপ সংস্করণ (ExifTool + ffmpeg ভিত্তিক)। নিচের কমান্ড কপি করে ব্যবহার করুন:

      pip install piexif pikepdf python-docx openpyxl
# একটা ফাইল ক্লিন
python metadata_cleaner.py photo.jpg --preset max-privacy
# পুরো ফোল্ডার, রিকার্সিভ + ব্যাকআপসহ
python metadata_cleaner.py ./photos --recursive --backup ./backup --report report.txt
# ভিডিও (ffmpeg লাগবে)
python metadata_cleaner.py video.mp4 --remove gps,author
# ফোল্ডার ওয়াচ: নতুন ফাইল এলেই অটো-ক্লিন
python metadata_cleaner.py --watch ./incoming --preset social
# Windows .exe বানানো
pip install pyinstaller
pyinstaller --onefile --name MetadataCleaner metadata_cleaner.py
      সব প্রসেসিং এই ব্রাউজারেই হয় — ফাইল কোথাও আপলোড হয় না। পাসওয়ার্ড-দেওয়া (encrypted) ফাইল স্ক্যানে চিহ্নিত হবে, কিন্তু পাসওয়ার্ড ছাড়া ক্লিন করা যাবে না।
